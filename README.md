## 便宜 VPS 的价格档位：差几十美元，差的是线路

同样的 1GB 内存 + 1TB 流量，价格可以从每年十几美元跨到一千多美元，价差的核心变量只有一个：回程线路。

目前市面上便宜国外 VPS 大致分三档：

1. **普通国际线路档**（$10–50/年）：代表如 Racknerd 的常规机器、搬瓦工的 MINICHICKEN（$19/年，弗里蒙特机房，HE 线路）。这个档位的机器白天用没问题，晚高峰国内访问会明显变慢甚至丢包。拿来练手、跑脚本、挂低频服务完全够。
2. **优化线路档**（$50–170/年）：搬瓦工的 CN2 系列（CN2 GT 回程）和 CN2 GIA-E 系列（三网 CN2 GIA 回程）在这一档。CN2 GIA-E 机房电信线路实测平均延迟约 161ms，三网丢包率接近 0，这个指标在中美之间属于民用最低延迟水平之一。
3. **直连/近场高端档**（$900+/年）：香港 CN2 GIA、新加坡 CN2 GIA 这类三网直连机房，延迟最低，但月付 $89.99 起，已经和“便宜”没什么关系了。

一句话决策：白天用、跑后台任务，选第一档省钱；有国内访问需求（博客、自用代理、轻量业务），第二档才叫便宜；延迟敏感且预算充足，再考虑第三档。
